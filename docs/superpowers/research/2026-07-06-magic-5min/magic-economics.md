## 2. Юнит-экономика трёх wow-бюджетов

Базовые цифры: 251 рег/мес; 1 кредит = 0.15₽; markup 3.0 → маржа плана ≈67%; contribution с 490₽ ≈ **327₽**, с 1490₽ ≈ **993₽**.

### (a) Бюджет 0₽ — магия только из чата (в рамках 35 кредитов)

| Показатель                  | Значение                                                                                                                       |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Инкрементальный COGS/юзер   | **0₽** (себестоимость 35 кредитов ≈1.75₽ — уже baseline)                                                                       |
| Расход на 251 рег/мес       | 0₽ сверху (baseline ≤440₽/мес и так тратится)                                                                                  |
| Break-even конверсия в 490₽ | **любая >0%**                                                                                                                  |
| Break-even в 1490₽          | любая >0%                                                                                                                      |
| Риск абьюза                 | Минимальный: фармить аккаунты ради \~5₽ чат-кредитов бессмысленно                                                              |
| Защита                      | Текущая (TG-auth) достаточна                                                                                                   |
| **Слабость**                | Текстовый wow слабый: 35 кредитов ≈ пара ответов дорогой модели. Не решает проблему «0 платежей» — это статус-кво с косметикой |

### (b) Бюджет 10–15₽ — 1–2 картинки nano-banana (COGS 6–13₽/шт)

Расчёт по средним 12.5₽/юзер при 100% активации; реалистично активируют \~50–60% → **эффективно \~7₽/рег**.

| Показатель                                 | 100% активация | Реалистично (55%) |
| ------------------------------------------ | -------------- | ----------------- |
| Расход на 251 рег/мес                      | \~3 100₽/мес   | **\~1 700₽/мес**  |
| BE-конверсия в 490₽ (gross)                | 2.6%           | 1.4%              |
| BE-конверсия в 490₽ (по марже 327₽)        | 3.8%           | **2.1%**          |
| BE-конверсия в 1490₽ (по марже)            | 1.3%           | 0.7%              |
| С учётом retention 3 мес (LTV-маржа ≈985₽) | 1.3%           | **0.7%**          |

Риск абьюза: **средний**. Мотив мультиаккаунтинга есть (картинки без VPN), но ценность одного аккаунта 6–13₽ — фарм невыгоден при базовой защите.
Защита: 1-я картинка — только после 2–3 осмысленных сообщений в чате (earned magic, отсекает ботов); 2-я — за возврат на D1; dedupe по TG-ID + device fingerprint; rate-limit по IP-подсети; выдача только через UI (не API); низкий приоритет очереди для free.

### (c) Бюджет \~50₽ — картинка + 5-сек видео seedance-fast (\~15₽)

| Показатель                      | 100% активация | Реалистично (45% доходят до видео) |
| ------------------------------- | -------------- | ---------------------------------- |
| Расход на 251 рег/мес           | \~12 550₽/мес  | **\~6 300₽/мес**                   |
| BE-конверсия в 490₽ (gross)     | 10.2%          | 5.1%                               |
| BE-конверсия в 490₽ (по марже)  | **15.3%**      | 7.6%                               |
| BE-конверсия в 1490₽ (по марже) | 5.0%           | 2.5%                               |
| С retention 3 мес               | 5.1%           | 2.5%                               |

Риск абьюза: **высокий**. 50₽ ценности на аккаунт — уже мотив для фарма (генерация видео для контент-ферм). Защита потребует телефон-верификации или карты — что убивает сам онбординг.

## 3. Рекомендация

**Выбрать (b) \~12₽ с каскадной выдачей, (c) — только как таргетированный слой для юзеров с сигналом покупки.**

Аргументы:

1. **(a) не решает проблему.** Конверсия сейчас 0% при текстовом онбординге — значит текстовый wow уже доказанно не работает. Экономия 1 700₽/мес не стоит ещё одного месяца нулевой выручки.
2. **(b) — асимметричная ставка.** Риск ограничен \~1 700–3 100₽/мес (цена одной пиццы-вечеринки), а break-even с учётом 3-мес retention — 0.7–1.3%, ниже нижней границы индустрии для freemium (1–5%). Даже single-month маржа окупается при 2.1% — достижимо.
3. **(c) целиком — преждевременно.** BE 5–15% при текущих 0% — азартная ставка без данных. Но видео как **второй шаг** для тёплых (зашёл на прайсинг / упёрся в лимит / вернулся D1-D3) — это уже не 251 юзер, а \~30–50, т.е. \~750₽/мес доп. расхода при куда более высокой ожидаемой конверсии сегмента.

**Чувствительность (бюджет b, эффективные 7₽/рег, маржа-базис, один месяц подписки):**

| Конверсия в 490₽ | Выручка-маржа/рег | P\&L на рег         | P\&L на 251 рег/мес                    |
| ---------------- | ----------------- | ------------------- | -------------------------------------- |
| 1%               | 3.3₽              | **−3.7₽**           | −930₽/мес (терпимо: это цена обучения) |
| 2%               | 6.5₽              | \~breakeven (−0.5₽) | −125₽/мес                              |
| 5%               | 16.4₽             | **+9.4₽**           | +2 360₽/мес (+ хвост retention)        |

С retention 3 мес плюс даже при 1% инициатива в плюсе (+2.9₽/рег). Kill-критерий: если через 2 месяца conversion < 0.5% и activation до wow < 30% — сворачивать (b), возвращаться к диагностике воронки, а не наращивать бюджет.

## 4. Дизайн триггера первой оплаты

Главный факт: **0 платежей за месяц** означает, что paywall либо не встречается, либо встречается до возникновения ценности. Триггер должен быть **событийным, а не временны́м**.

**Момент (кредитный голод на пике ценности):**

- Показывать paywall не «когда кончились кредиты», а когда юзер **хочет повторить успех**: сгенерил картинку → жмёт «ещё вариант»; получил видео → жмёт «сделать длиннее/другое»; выбрал locked-модель (уже есть механика locked-model upsell в Light-режиме — переиспользовать).
- Кредиты сжигать _видимо_: тающий счётчик у поля ввода, мягкие предупреждения на 50% и 80% («осталось \~2 картинки»). Внезапный отказ = ощущение обмана.

**Форма (честность через reciprocity):**

- Экран оплаты открывается рекапом: «За 5 минут вы бесплатно получили: 4 ответа GPT-5, 2 картинки, видео. Это стоило бы $X у трёх разных сервисов + VPN». Юзер платит после того, как уже получил, — это ощущается честно.
- Никакого fake-таймера и dark patterns — аудитория обожглась на серых VPN-сервисах, доверие — главный барьер.

**Механика первого платежа:**

- **Не trial с автосписанием** — в РФ-эквайринге это трение + негатив; и не скидка на подписку навсегда.
- Рекомендуется **интро-оффер: первый месяц 490₽ → 290₽**, окно 48 часов после первого wow-события (не после регистрации!). Якорение: рядом всегда полная цена и план 1490₽ (decoy — делает 490₽ «разумным выбором»).
- Альтернатива для сомневающихся — **микро-top-up 99₽** («ещё 10 картинок»): снимает страх подписки, создаёт первый платёж (снятие барьера «я уже платил здесь» — главный предиктор второго платежа).

**Канал доставки триггера — только in-app.** Известное слепое пятно: TG-native юзеры недостижимы по email, и бот не может писать первым тем, кто не стартовал @gptwebrubot. Значит offer-баннер и RetryModal внутри приложения — единственный надёжный канал; пуш в TG — только тем, кто стартовал бота (добавить «включи напоминание в TG о бонусе D1» как шаг онбординга — это заодно открывает канал реактивации).

**Метрики триггера:** paywall-views/рег, view→pay, доля 290₽-оффера vs top-up 99₽, время от wow до оплаты. Если view→pay > 10%, а paywall-views/рег < 20% — проблема в воронке до paywall, не в цене.
