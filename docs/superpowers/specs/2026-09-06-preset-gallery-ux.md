## 1. Макет: одно решение на десктоп, одно на мобилу

### Решение

**Десктоп — гибрид:** слева остаётся `FlowSidebar` (создание), справа над сеткой — **липкая верхняя полоса просмотра** (поиск · фильтр модели · чипы категорий · сортировка). Левой навигации по категориям в стиле meigen **не делаем**.

**Мобила — верхняя полоса + полноэкранный экран создания по маршруту** (`?view=create`), нижний шит `MobileFlowSheet` уходит.

### Почему так, а не meigen-like sidebar

1. **Место.** Левая колонка уже занята панелью создания, и для новичка она важнее категорий: именно там «что выбрано → сгенерировать». Две левые колонки = либо плитки 196 px, либо горизонтальный скролл страницы.
2. **Модель поведения новичка.** Категория — это фильтр, который трогают 1–2 раза за сессию; создание — то, что трогают каждый раз. Фильтры живут там, где им место в антд/лобе — над контентом; постоянный вертикальный список на 12 категорий с 3–7 элементами внутри (см. счётчики из БД) выглядит пустым.
3. **1000+ элементов.** Плоская полоса чипов со счётчиками масштабируется до 20–30 категорий горизонтальным скроллом (это уже сделано в `5028623310`); дерево «Категории → Теги» появится не раньше, чем в каталоге будет ≥ 50 в каждой — тогда добавим второй ряд чипов (теги), не колонку.
4. **Пиксели meigen'а мы берём с сетки, а не с навигации:** плотная 4-колоночная masonry, реальные пропорции, круглый play-бейдж, маленькие зазоры, без подписей на десктопе — всё это в §3.

## 3. Анатомия карточки

Одна и та же `PresetCard`, два режима по `useIsMobile()` (уже используется внутри).

### Общее

- Корень — `<button type="button">` (как сейчас), `border-radius: 12px` (десктоп) / `10px` (мобила), фон `colorBgContainer`, граница `colorBorderSecondary`; выбранная — `2px colorPrimary`.
- Медиа-бокс: `aspect-ratio` = **реальная пропорция** `presetAspectRatio(preset)`, зажатая в диапазон `[9/16 … 2/1]` (w/h ∈ [0.5625, 2]) — новая `tileAspectRatio()` в `presetAspect.ts`. Больше 9:16 в высоту плитка не растёт (на мобиле это ≤ 304 px высоты, на десктопе ≤ 445 px), шире 2:1 — не сплющивается. Всё, что вне диапазона, `object-fit: cover`.
- Постер — `<img loading="lazy" decoding="async">`, под ним фон `colorFillTertiary` (это и есть скелетон: бокс уже нужного размера, CLS = 0). Постер не пришёл/404 → существующий градиент с заголовком.
- Бейджи (`New`, `Top`, `🔥`, `Тренд месяца`) — слева сверху, как сейчас; на мобиле рендерим **только первый**.
- **Play-бейдж** (только `modality === 'video'` или превью `.mp4`): круг 24 px (десктоп) / 28 px (мобила), справа сверху 8 px, `rgb(0 0 0 / 55%)` + `backdrop-filter: blur(4px)`, иконка `Play` 12 px белая залитая. `pointer-events: none`, `aria-hidden`. Прячется, пока плеер в состоянии `playing` (через `onPlayingChange`).

### Десктоп (~250–280 px)

```
┌──────────────────────────┐
│ New                   ◉▶ │  ← бейдж слева, play справа (8 px от краёв)
│                          │
│        постер            │  aspect = реальная (клэмп 9:16…2:1)
│                          │
│ ░░░░░░░░░░░░░░░░░░░░░░░░ │  hover-слой: градиент снизу 0→80 % чёрного на 55 % высоты
│ ЗАГОЛОВОК (13/700, upper)│
│ Описание RU / категория  │  11/400, 1 строка, ellipsis
│ @автор · ♥ 1,2 тыс.  [⤢] │  11/400 75 %; [⤢] 32×32 «Подробнее» → zoom
└──────────────────────────┘
```

- Текст **только в hover-слое** (уже есть в коде как `hoverOverlay`, `@media (hover:none){display:none}`). Постоянная подпись под медиа (`caption`, коммит `5cfb6ecbee`) на десктопе **не рендерится** — это и есть «дельта к Ф3».
- `CATEGORY_HINTS` (подсказка «что писать») из hover-слоя убираем — она была нужна, пока промпт был обязателен. Место отдаём автору/популярности.
- Кнопка «Подробнее» переезжает из правого верхнего угла (там теперь play-бейдж) в правый нижний угол hover-слоя, 32×32, `pointer-events: auto` только при hover (как сейчас `preset-zoom-btn`). Клик по любой другой точке = применить стиль.
- Hover: `translateY(-2px)` + оверлей; `@media (prefers-reduced-motion: reduce)` — без трансформа. `:focus-visible` — `outline: 2px solid colorPrimary; outline-offset: 2px` и **тот же оверлей, что и на hover** (клавиатурный юзер тоже должен видеть текст).

### Мобила (~170 px)

```
┌────────────────┐
│ New         ◉▶ │
│                │
│     постер     │  aspect реальная (клэмп), вся плитка — одна цель тапа
│                │
├────────────────┤
│ Заголовок      │  12/600, 1 строка, ellipsis, colorText
│ Кино · ♥ 1,2 т │  11/400, 1 строка, colorTextTertiary
└────────────────┘  подпись фикс. 40 px (8+14+2+13+… с паддингами) — известна заранее для masonry
```

- Подпись — **под** медиа на фоне страницы (контраст гарантирован токенами, не градиентом).
- Строка 2: русское `description` если есть, иначе `categoryLabel(category)`; затем ` · ♥ N` если `popularity !== null`. Автор на плитке не показывается — он в карточке выбранного стиля и в зум-модале (это и закрывает требование атрибуции там, «где юзер реально генерит»).
- Никакой zoom-кнопки на плитке: 28 px полупрозрачная `zoomBtnTouch` — цель < 40 px и вторая цель на 170 px плитке. Детали — с экрана создания («Подробнее» в `PresetThumbCard`).
- Тап: `:active` — `transform: scale(0.98)` 80 мс (без reduced-motion).
- Минимальные цели: плитка ≥ 170×96 px, чипы 40 px (уже), CTA 48 px, «Подробнее»/«Убрать» 40 px.

### Медленная сеть

- Пока сетка не измерена (первый кадр) — рисуем 8 скелетонных боксов по средней пропорции 3:4 в тех же колонках, чтобы не мигал пустой экран; после `ResizeObserver` — реальная раскладка. На практике это один `useLayoutEffect`.
- Постеры: у ингеста уже webp; добавить в конвейер ограничение ширины 480 px (для 280 px плитки при DPR 2 хватает 560 → 480 приемлемо) — это ingest-задача вне этого документа, здесь фиксируем требование.
- Видео стартует только при hover/самая-видимая-1 (как есть).

Чип = `Button size="small" shape="round"` (32 px десктоп) / `size="middle"` (40 px мобила), `variant="filled"`, токены antd; активное состояние поповера — `colorPrimaryBg`. Не изобретаем свой чип — тот же, что `CategoryChips`, только 32 px на десктопе.

### Состояние чипа модели относительно стиля

- Текущая модель = `preset.recommendedModelId` → без пометок.
- Стиль выбран, но модель другая (юзер нажал «Вернуть» или сменил сам) → перед именем точка `colorWarning` 6 px, `Tooltip`: «Стиль рассчитан на Nano Banana Pro. Результат может отличаться».
- Рекомендуемая модель залочена тарифом → в чипе `Lock` 12 px + `Tooltip`: «Рекомендуемая — Nano Banana Pro, на тарифе Базовый».

### Деградация на 360 px

Полоса — `display:flex`, две группы: **левая скроллится** (`overflow-x:auto`, скрытый скроллбар, правый fade 16 px), **правая зафиксирована** (`≈ N кр` + `⚙`). Прикидка для image на 360 px с паддингом 16: `[● Nano Banana Pro ▾]` ≈ 150 + `[3:4 ▾]` ≈ 64 + зазоры 8 = 222 ≤ 328 − 110 (правая группа) — влезает без скролла; video добавляет `[5 с ▾]` ≈ 60 → 282 > 218 → левая группа скроллится, стоимость и ⚙ остаются на месте. Имя модели в чипе обрезается до 14 симв. с ellipsis (`Nano Banana P…`), полное — в `title`.

### Авто-переключение: `usePresetModelSwitch(modality)`

Новый хук в `features/Generators/`, вызывается из `FlowMainArea.onPresetSelect` после `hydratePreset` и из `usePresetDeepLink`:

1. `recommendedModelId` пуст или равен текущей → ничего.
2. Рекомендуемой нет в `enabled*ModelListByMode(uiMode)` (Pro-юзер отключил провайдер `lobehub`) → не переключаем, чип показывает точку-предупреждение.
3. `requiredPlanForModel(recommendedModelId)` (кэш 5 мин; префетч на `pointerenter`/первый тач по плитке, чтобы решение было мгновенным):
   - **не залочена** → `setModelAndProviderOnSelect(recommendedModelId, 'lobehub')`; тост `message.open({ key:'preset-model-switch', duration: 5 })`: «Модель переключена на **Nano Banana Pro**   [Вернуть]». «Вернуть» — `Button type="link" size="small"` внутри контента тоста; восстанавливает `(prevModel, prevProvider)`, закрывает тост. Ключ один → второй быстрый выбор стиля заменяет тост, а не стопкует.
   - **залочена** → модель не трогаем, стиль остаётся выбранным; десктоп — `UpsellModal`, мобила — `LockedModelUpsellSheet`, обе с `fallbackAction = { label: 'Продолжить на GPT Image 2', onClick: close }`. Закрытие любым способом = fallback (стиль применён, модель прежняя, чип с замком).
4. Тот же хук через полгода обслуживает `requiresImage` (Ф5): если у пресета `requiresImage && !supportsImageUrl(current)` → переключить на `…/image-to-video`-вариант той же логикой; в `MobileFlowContent`/`FlowSidebar` при `requiresImage` и пустом `imageUrl` CTA дизейблится с подписью «Добавьте фото» — но это Ф5, здесь только совместимость интерфейса хука.

Тост не показываем при deep-link (`?preset=` с главной) — там переключение ожидаемо; вместо тоста — состояние чипа.

## 6. Таксономия: перемаркировать сейчас, не переименовывать слаги

Срез БД (активные): video — action 8, cinematic 7, vlog 7, 3d 4, anime 4, effects 3, ad 3, fantasy 3, character 1 (camera 0, ambient 0 — есть только в очереди); image — portrait 11, artistic 7, realistic 6, landscape 5, product 5, anime 4. Фолбэк ингеста — `trends`.

## 8. Риски и доступность

| Риск | Митигация |
|---|---|
| **Клавиатура в masonry.** Визуальный порядок ≠ строгий порядок чтения (элемент 5 может оказаться выше элемента 4 в соседней колонке) | DOM-порядок = ранг; Tab идёт по рангу, что для «подборки» осмысленнее геометрии. `aria-label` карточки = заголовок; контейнер `role="list"`, карточки `role="listitem"` вокруг `<button>`. Кнопка «Показать ещё» остаётся клавиатурным входом в догрузку. Стрелочную навигацию не делаем — это не toolbar-виджет, а лента. |
| **Абсолютное позиционирование + фокус-кольцо** обрезается | У контейнера `overflow: visible`; кольцо `outline-offset: 2px` при `gap: 8` не перекрывает соседа. |
| **reduced-motion** | Уже: плеер не регистрируется. Добавить: без `translateY` на hover, без `scale` на тапе, без shimmer в скелетоне, тост без анимации не трогаем (antd уважает `prefers-reduced-motion` частично — допустимо). |
| **Контраст** | Мобильная подпись — токены на фоне страницы (≥ 4.5:1 по умолчанию темы). Десктопный hover-текст — белый на градиенте до 80 % чёрного: заголовок/описание ≥ 4.5:1 на нижних 35 % плитки, где и лежит текст; строку 75 % белого (`hint`) убираем, автор/♥ — 90 %. Play-бейдж — белый на 55 % чёрного + blur: ≥ 3:1 для не-текстовых элементов на любых постерах, кроме почти чёрных, где он не нужен. `Top` — чёрный текст на `#facc15` (≥ 4.5:1). |
| **Неверная/отсутствующая `aspect_ratio`** → cover-кроп или фолбэк 3:4 | Ингест пропускает только белый список; у ручных 76 строк есть значения (срез БД). Клэмп защищает от вырожденных значений. |
| **SSR/первый кадр**: `useIsMobile` из `useResponsive` и ширина контейнера неизвестны до маунта | Скелетон-раскладка 8 боксов в `useLayoutEffect` → реальная за один кадр; никакого «прыжка» контента, потому что размеры плиток не зависят от загрузки медиа. |
