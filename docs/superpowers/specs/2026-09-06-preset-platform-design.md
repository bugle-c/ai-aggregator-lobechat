## Цель

Превратить статичный набор из 76 рукописных пресетов в самонаполняющуюся витрину стилей:
внешний ингест с атрибуцией на первоисточник, поиск/фильтры/пагинация под тысячи элементов,
исправленный путь «посмотрел стиль → сгенерировал», плюс поддержка image-to-video пресетов.

## Источник данных (проверено вживую)

- **API:** `https://www.meigen.ai/api/videos?offset=N` и `/api/images?offset=N`, шаг 20, поля `hasMore`/`totalCount`.
- **Доступ:** домен под Cloudflare managed challenge — прямые запросы (curl/headless/боты) отдают 403.
  Работает через reader-proxy: `https://r.jina.ai/<url>` с заголовками `x-respond-with: text`, `x-no-cache: true`.
- **Медиа-CDN открыт напрямую (без челленджа):**
  `https://images.meigen.ai/videos/<id>/video.mp4`, постер `/thumb.jpg`, картинки `https://images.meigen.ai/tweets/<id>/<n>.jpg`.
- **Поля элемента:** `id` (снежинка X), `prompt`, `title` (обрезанный промпт), `author{name,username,avatar,verified}`,
  `stats{likes,views,retweets}`, `model`, `aspectRatio`, `postedAt`, `source:"twitter"`, `videoUrl`/`image`.
- **Атрибуция выводится:** источник = `https://x.com/<username>/status/<id>` (резолвится 200), автор = `https://x.com/<username>`.
- **Объём:** видео-каталог \~1000 (исчерпывается на offset \~1000), 978 с рабочими роликами; картинки — отдельный каталог.
- **Гочча:** `referenceInputContract`/`contentType`/`promptReady` в выдаче константы (`legacy`/`gallery_video`/`true`) —
  как признак i2v **не годятся**, детект только по тексту промпта.

## Медиа-конвейер (проверен насквозь)

`скачать с CDN → ffmpeg → залить в наш RustFS → отдаётся с ask.gptweb.ru/s3/lobe/presets/…`

- Видео: `-t 5 -an -vf scale=640:-2 -crf 30 -preset slow -movflags +faststart` → 11 МБ ⇒ **77–440 КБ**.
- Постер: `thumb.jpg` источника → webp.
- Уже залито **40 t2v-роликов** (ждут строк в БД с атрибуцией — см. Ф1).

## Фазы

### Ф0 — починить сломанное

Маппинг `params_lock` на реальные ключи схемы (whitelist, а не спред `as any`), исправить тест и
`KNOWLEDGE.md`; оживить `?preset=` через `getBySlug` на обеих flow-страницах; `pointer-events:none`
для скрытой кнопки зума + видимая точка входа в детали на тач-устройствах.

### Ф1 — схема и атрибуция

Миграция: `external_id` (unique), `source_platform`, `source_url`, `author_name`, `author_url`,
`author_avatar`, `poster_url`, `popularity` (int), `requires_image` (bool), `ingested_at`, `license`.
Показ автора и ссылки «Источник ↗» в `PresetZoomModal` (футер) и в `PresetThumbCard` (карточка выбранного
стиля — видна там, где юзер реально генерит). Бэкфилл 40 залитых роликов.

### Ф2 — данные под масштаб

`presets.list`: cursor-пагинация + `limit`, не отдавать `prompt_template` в списке (только в `getBySlug`).
Фасеты категорий из БД со счётчиками вместо хардкода. Поиск по `title + description + category`
(+ колонка русских алиасов/тегов), триграммный индекс, дебаунс. Флаг `featured` для главной + серверный limit.

### Ф3 — переработка витрины

Упорядоченная CSS-grid сетка вместо multicol; бесконечная лента с виртуализацией; постер-первым,
воспроизведение по наведению/тапу с паузой за экраном; постоянная русская подпись на карточке;
чипы категорий со счётчиками (скроллируемые); входы «Топ / Новое / Тренды»; предпросмотр итогового
промпта (свёрнут) с возможностью отредактировать или отцепить пресет.

### Ф4 — автосинхронизация

Cron (раз в сутки): тянуть `/api/videos` и `/api/images` с offset 0 до первой страницы, где все `external_id`
уже известны → фильтры → медиа-конвейер → вставка с атрибуцией.

**Правила автопубликации** (`active=true` сразу) — все условия обязательны:
безопасность (стоп-лист: nsfw/насилие/оружие/наркотики/политфигуры/бренды),
латиница ≥90% в первых 200 символах промпта, длина промпта ≥80,
`aspectRatio` из белого списка (16:9, 9:16, 1:1, 4:3, 3:4), ролик скачался и прошёл ffmpeg,
`likes ≥ 50`, не дубль по `external_id`, ≤2 пресета на автора за один прогон.
Не прошедшие — `active=false` (очередь), не удаляются.
Провал синхронизации → TG-алерт; уже загруженное живёт локально и не зависит от источника.

### Ф5 — i2v-пресеты

`selectPreset` переключает модель, если `recommended_model_id` содержит `image-to-video`;
бейдж «нужно фото» на карточке; слот референс-картинки уже есть в ConfigPanel.
Ингест 122 i2v-кандидатов (детект по тексту промпта: `@image1`, `uploaded image`, `reference face`).

## Риски

1. **Зависимость от чужого источника и от reader-proxy** — оба могут отвалиться. Митигация: всё
   скачанное лежит у нас, каталог не деградирует; алерт на провал; ингест изолирован от рантайма.
2. **Правовой** — ролики авторов из X. Митигация: обязательная атрибуция с ссылкой на исходный пост
   (как у источника), `license`-поле, удаление по запросу автора.
3. **Качество/безопасность контента** — автопубликация. Митигация: строгие фильтры выше + очередь + возможность быстро снять с публикации (`active=false`).
4. **Масштаб UI** — без Ф2/Ф3 тысяча пресетов положит галерею. Поэтому Ф4 идёт после них.

## Вне скоупа V1

- Админ-страница модерации очереди (пока — SQL).
- Ингест из X напрямую (нужен платный API).
- Перевод промптов на русский (промпт уходит в модель как есть; русифицируются только заголовки/подписи).
